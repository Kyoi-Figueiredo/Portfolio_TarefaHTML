# Meu Mini Portfólio

Este projeto foi desenvolvido como parte de uma atividade prática de HTML do curso de programação para mulheres do ICMC-USP.

A proposta é criar uma página pessoal para apresentar um pouco sobre mim, meus interesses e minha jornada de aprendizado na programação.

## Tecnologias utilizadas

- HTML5

## O que você encontrará neste projeto

- Apresentação pessoal
- Fotografia de perfil
- Listas de filmes, séries e preferências pessoais
- Link para meu Instagram
- Áudio de fundo
- Tabela com tecnologias que estou aprendendo

## Como visualizar

Baixe ou clone este repositório e abra o arquivo `meu_mini_portfolio.html` em um navegador.
